# Package index

## Datasets

Three nested tibbles. Join `volcanoes` -\> `eruptions` on
`volcano_number`, and `eruptions` -\> `events` on `eruption_number`.

- [`volcanoes`](https://moderndive.github.io/volcanoes/reference/volcanoes.md)
  : Holocene volcanoes
- [`eruptions`](https://moderndive.github.io/volcanoes/reference/eruptions.md)
  : Volcanic eruptions
- [`events`](https://moderndive.github.io/volcanoes/reference/events.md)
  : Eruption events
